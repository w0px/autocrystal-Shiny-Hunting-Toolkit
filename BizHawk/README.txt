This folder holds BizHawk 2.11.1, the emulator autocrystal runs in.

The release download (Releases on the autocrystal GitHub page) already
has it in here - nothing to do.

Got autocrystal straight from the repository instead? Download
BizHawk-2.11.1-win-x64.zip from https://github.com/TASEmulators/BizHawk/releases
and extract its contents into this folder, so that EmuHawk.exe sits right
here next to this file. Then double-click start.exe.

(Without it, start.exe looks for an installed BizHawk on this PC or asks
you to pick EmuHawk.exe. Only BizHawk 2.11.1 is tested.)
